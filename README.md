# Student Management System

A web application for managing student records featuring traditional Java Web components (Servlets, JSP, JDBC)

---

## Features

- **Student Record Management (CRUD):** Add, view, edit, and delete student data.
- **Classic Java Web Backend:** Servlet-based HTTP endpoint routing with pure JDBC operations.
- **Database Persistence:** Data storage managed via MySQL and MySQL Connector/J.

---

## Tech Stack

### Backend
- **Language:** Java (JDK 17+)
- **Server:** Apache Tomcat
- **Core Web Specs:** Java Servlets (Jakarta EE / Java EE), JSP
- **Database Connectivity:** JDBC (Java Database Connectivity)
- **Database Driver:** MySQL Connector/J (`mysql-connector-j`)

### Frontend
- **Text:** HTML, XML
- **Styling:** CSS
- **HTTP Client:** Fetch API

### Database & Utilities
- **Database:** MySQL Server
- **Build & Dependency Management:** Apache Maven
